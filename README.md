## 核心优化手段

### 1. 官网结构化数据（已完成）
`website/index.html` 中嵌入了以下 JSON-LD 结构化数据：
- **Dentist**: 诊所基本信息（名称、地址、电话、服务目录、营业时间、评价）
- **Person × 5**: 每位医生的独立标记（姓名、资质、擅长领域、所属机构）
- **FAQPage**: 12个口腔常见问题的结构化问答标记
- **BreadcrumbList**: 面包屑导航
- **WebSite**: 网站整体信息

### 2. 关键词策略（已完成）
覆盖品牌词、地域+服务词、通用词、长尾问题词四个层级，详见 `strategy/keyword-plan.md`。

### 3. 字节生态布局（策略已制定）
需要在以下平台开设账号并持续发布内容：
- **头条号** — 口腔科普文章
- **抖音企业号** — 医生科普短视频
- **悟空问答** — 口腔问题直接回答

## 关键成功因素

1. **字节生态内容权重**：豆包优先检索字节系内容，头条号+抖音是核心战场
2. **结构化数据完整性**：JSON-LD标记帮助AI准确理解和提取你的内容
3. **内容持续更新**：AI搜索倾向于推荐活跃更新的高质量内容源
4. **品牌语义关联**：在所有平台统一使用"忠一口腔"品牌名
5. **FAQ内容精准匹配**：问答格式的内容最容易被AI引用为回答来源
